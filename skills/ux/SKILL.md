# UX Skill

## Purpose

Create simple user flows that help users complete the primary business task.

## Rules

- Identify the primary user goal.
- Minimize unnecessary steps.
- Make important actions obvious.
- Provide clear feedback after user actions.
- Handle loading, empty and error states.
- Design for mobile where relevant.
- Keep navigation predictable.
- Do not add functionality without a user need.
- Do not use deceptive or manipulative interaction patterns.
