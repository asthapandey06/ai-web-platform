# WebsiteOS Skills

Skills are reusable instructions and engineering knowledge consumed by AI agents.

## Rules

- Skills define HOW work should be performed.
- Skills must be reusable across client projects.
- Skills must not contain client-specific requirements.
- Skills must not duplicate subagent responsibilities.
- Prefer simple, proven patterns.
- Avoid premature abstractions and infrastructure.
- Preserve existing project conventions.
- Never invent business requirements.

## Skill Categories

- architecture — system structure and boundaries
- frontend — React/TypeScript implementation
- backend — Node.js/TypeScript/Express implementation
- database — PostgreSQL/data modeling
- api — API design and implementation
- authentication — auth/OAuth/JWT patterns
- integrations — external-system integrations
- webhooks — webhook handling
- queues — asynchronous processing
- automation — business workflow automation
- testing — unit/integration/E2E testing
- security — application security
- ui-design — visual implementation rules
- ui-ux — UX decisions and interaction patterns
- ui-components — reusable component implementation
- accessibility — accessibility requirements
- seo — technical SEO
- local-seo — local business SEO
- content — website content rules
- conversion — conversion-oriented implementation
- website-strategy — website structure and business goals
- deployment — build/deployment practices
- database — persistence and data integrity
- dental — dental-domain knowledge
